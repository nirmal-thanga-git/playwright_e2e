Introduction of TypeScript

What is TypeScript?
TypeScript is superset of JavaScript - it adds extra features of JavaScript

It compiles (converts) into regular JavaScript, so it runs anywhere JavaScript does

Files end in .ts (instead of .js)

The TypeScript compiler converts it into JavaScript (.js files). We can also execute .ts files directly.

TypeScript just adds optional features (like types) - complete object oriented to make coding safer and easier.

use of ts?
Helps catch mistakes early (before runnig the code).
makes large projects easier to manage.

variable redeclaration is not allowed in typescript - statically types language (type safety)
